### Quyết định / bài học

1. **Di cư ở lifespan, KHÔNG ở lúc import.** Bản đầu gọi `migrate_legacy()` ngay dưới
   `FastAPI(...)` → `scripts/migrate_ota.py --dry-run` dời file THẬT, vì `app/__init__.py`
   import `app.main` (mọi script/test import `app.*` đều chạy main.py). Bắt được nhờ chạy thử
   dry-run trên thư mục giả — không phải nhờ test (test gọi thẳng `ota.migrate_legacy`).
   Luật: **main.py không được có tác dụng phụ ghi đĩa lúc import** ngoài `mkdir`.
2. `/ota/check` với `product` sai cú pháp trả `reason:"product"` chứ không đoán về kho legacy:
   máy khai product là firmware mới, nó cũng sẽ đối chiếu manifest — fail-closed không tốn gì.
3. `version` trong `/ota/check` GIỮ = tên file (firmware ≤ v2.4.5 so đúng chuỗi); `ver` mới là
   version thật. Kho legacy giữ tiền tố `fbt_`; kho khác `<product>_v<ver>.bin`.
4. Test env: `test_api.py` gán đè `os.environ[...]` SAU khi module khác đã import `app.main` →
   hằng `ATE`/`DATA` trỏ vào thư mục app không dùng (4 test fail khi đảo thứ tự). Đổi sang
   `setdefault` ở mọi module test.
5. Heredoc bash trong box này nuốt `\\` → regex `[^/\\]` thành `[^/\]` (lỗi compile). Viết file
   Python có backslash bằng Write/Edit tool, không heredoc.
