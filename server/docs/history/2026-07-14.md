## Tài khoản đăng nhập app: chuyển từ Google Sheet về Postgres (bảng `users`)

Bối cảnh: app Flutter đăng nhập qua Apps Script `userAuth.js` + Google Sheet.
Chuyển toàn bộ (login + đổi mật khẩu/email + quản lý user) về server này.

- **`app/auth.py` (MỚI)** — dispatch action theo ĐÚNG hợp đồng JSON của
  `userAuth.js`: `login | changePassword | changeEmail | listUsers | saveUser |
  deleteUser`. Response LUÔN HTTP 200 `{ok:true,...}`/`{ok:false,error}` (app đọc
  cờ `ok`, không đọc status). Action admin re-verify `adminUser+adminPassword`
  mỗi lần, yêu cầu role `root`; guard "không xoá/hạ quyền root cuối cùng".
- **`app/main.py`** — route `POST /auth` (Bearer token cửa chung như `/login`),
  đặt **TRƯỚC** catch-all POST `/{_path:path}` (đặt sau là bị ingest nuốt).
  Đọc body thô (app gửi `Content-Type: text/plain`) — KHÔNG dùng Pydantic.
- **`app/logic.py`** — `verify_password` hỗ trợ thêm hash **`sha256$<salt>$<hash>`**
  di cư từ Sheet (hash = sha256(salt + password), salt nối CHUỖI) → import
  nguyên hash, user cũ login được ngay, không cần biết/đổi mật khẩu; đổi mật
  khẩu trên server tự nâng scrypt. Thêm `parse_ids`/`parse_active` (khớp
  `parseIds_`/`parseActive_` của userAuth.js).
- **`app/db.py`** — `get_user` chuyển sang so khớp KHÔNG phân hoa/thường (khớp
  hành vi Sheet); thêm `upsert_user` (password/email `None` = giữ cũ),
  `delete_user`, `set_password`, `set_email`, `count_roots`.
- **`deploy/schema.sql`** — thêm `GRANT DELETE ON users TO engineer` (deleteUser).
  Server đang chạy phải chạy lại lệnh GRANT này (bảng cũ chỉ có SELECT/INSERT/UPDATE).
- **`scripts/import_accounts.py` (MỚI)** — di cư: export tab Accounts của Google
  Sheet ra CSV → `python scripts/import_accounts.py accounts.csv`. Idempotent
  (upsert theo username); hash `sha256$…` giữ nguyên, plaintext còn sót → băm
  scrypt, ô password trống → giữ mật khẩu hiện có trên server.
- **Test**: `tests/test_logic.py` +4 (sha256 legacy, parse_ids/active),
  `tests/test_api.py` +1 (`/auth` cần token, luôn 200 `{ok}`, không bị catch-all
  nuốt). E2E với Postgres thật (docker): import CSV → login hash legacy →
  saveUser/changePassword (nâng scrypt)/changeEmail/deleteUser → guard root
  cuối → re-import idempotent: PASS toàn bộ.
- **Phía app** (repo `app/`): `AuthApi` thêm `headers` + factory
  `AuthApi.engineer()` → POST `{engineerUrl}/auth` kèm Bearer; 3 call site
  (login / thiết lập / quản lý user) chuyển hết. Hằng `kDefaultAuthApiUrl`
  (Apps Script) giữ làm đường lùi khẩn cấp.

### Việc cần làm khi deploy lên box
1. `git pull` + restart `fbt-receiver`.
2. `sudo -u postgres psql mydb -c 'GRANT SELECT, INSERT, UPDATE, DELETE ON users TO engineer;'`
3. Export Sheet Accounts → CSV → `~/fbt_server/venv/bin/python scripts/import_accounts.py accounts.csv`.
4. Thử `POST /auth {action:"login",...}` bằng curl (token đọc từ env, đừng dán trần).

## Host app WEB trên chính server (cùng ngày, sau phần auth)

- **`main.py`**: mount tĩnh **`/app`** ← `config.WEB_DIR` (mặc định `~/fbt_server/web`,
  env `FBT_WEB_DIR`; thiếu thư mục thì bỏ qua — máy dev/test không cần). App web =
  Flutter `build web --base-href /app/` scp nguyên thư mục vào `~/fbt_server/web/`.
  **Cùng origin với API → hết CORS** cho /auth, /sessions, /devices trên web.
- **`/auth` BỎ gate Bearer**: web public không nhúng token vào JS được (ai tải trang
  cũng móc ra) — mọi action vốn tự gate bằng mật khẩu (đúng mô hình Apps Script /exec
  công khai cũ). Đánh đổi: login/admin action lộ ra Internet như trước đây trên Apps
  Script; muốn chặt hơn sau này thì thêm rate-limit.
- **Login thành công trả thêm `apiToken`** (= RECEIVER_TOKEN): app lưu vào Cài đặt nếu
  đang trống → bản web sau đăng nhập tự có token gọi API Bearer. Đánh đổi (ngang bản
  desktop nhúng FBT_TOKEN): user hợp lệ nào cũng cầm token đọc toàn bộ API — lọc theo
  máy vẫn ở client (`canSee`).
- Test cập nhật: `/auth` không cần token, action admin sai mật khẩu → `{ok:false}`.
- URL dùng: **`https://fbt.basa-luma.ts.net/app/`** (Funnel forward nguyên domain → uvicorn).
- (Chiều cùng ngày) Redeploy `~/fbt_server/web/` với bản web có **tab Kỹ Thuật** (Web Serial +
  esptool-js, chỉ Chrome/Edge desktop) — thay đổi HOÀN TOÀN phía repo app, server chỉ nhận file
  tĩnh mới (`main.dart.js` + `esptool.js` 213KB); mount static đọc đĩa theo request nên **KHÔNG
  cần restart** service.
