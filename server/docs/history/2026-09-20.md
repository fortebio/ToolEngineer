### Thêm công cụ

- **`scripts/check_deploy.py`** (mới): so `openapi.json` public của prod với code local — in route chỉ-local /
  chỉ-prod / đổi chữ ký + md5 `app/*.py` bản CRLF (đối chiếu `md5sum` trên box vì openapi không phản ánh
  `logic.py`/`ota.py`/`config.py`). Exit 0 = giống hệt. Chạy được từ phiên AI (không SSH, không token) — thay cho
  đoạn script tạm mỗi lần deploy trước đây (09-12, 09-18).
- **`scripts/deploy.ps1 -Server`**: sau scp thêm bước `venv/bin/python -c 'import app.main'` trên box (in `IMPORT_OK`)
  — bắt ImportError/thiếu package TRƯỚC khi restart (gotcha: chép lẻ file → uvicorn không lên → mất `/ingest` cả
  fleet); hướng dẫn cuối in lệnh restart kèm `is-active`+journal, lệnh `check_deploy.py`, và lệnh **rollback** với
  đúng `app.bak.<stamp>` vừa tạo. Bỏ gợi ý `migrate_ota --dry-run` (kho đã di cư từ 09-12, server vẫn tự làm ở
  lifespan). File giữ UTF-8 BOM, `Parser::ParseInput` 0 lỗi, `-DryRun` chạy được.
