# Lịch sử chỉnh sửa — 2026-07-08

Thiết lập ban đầu cho FBT Home Server.

## Server (Debian)
- Cài Debian headless (không GUI), chọn OS tối ưu nhẹ cho server + database.
- Sửa lỗi user chưa có quyền sudo (`usermod -aG sudo`, phải login lại).
- Thiết lập SSH key từ laptop → server; xử lý sự cố tự khóa do tắt `PasswordAuthentication` trước khi key chạy.
- Cài PostgreSQL 17, tạo DB `mydb` + user `myuser`. Sửa cảnh báo locale `en_US.UTF-8`.
- Cố định IP bằng DHCP Reservation trên router.
- Cài Tailscale (server + laptop) để SSH/VS Code Remote-SSH từ xa; tắt key expiry cho node.
- Thiết lập `~/.ssh/config` (host `fbt-server`) + VS Code Remote-SSH.

## Code
- Thêm `receiver.py`: HTTP server bằng Python stdlib, nhận POST JSON từ thiết bị (vd `RPL02013`), lưu mỗi request thành 1 file `<id_device>_<ngày_giờ>.json` trong `~/fbt_server/data_plus/`. Đã test end-to-end. Chạy nền bằng systemd `fbt-receiver`, cổng 8080.
- Thêm xác thực token vào `receiver.py`: biến môi trường `RECEIVER_TOKEN`, yêu cầu header `Authorization: Bearer <token>` (hàm `check_auth` dùng `hmac.compare_digest`), thiếu/sai → 401. Đã test 401/200. Chuẩn bị mở endpoint ra Internet an toàn.
- Quyết định dùng **Tailscale Funnel** (không phải Vercel — Vercel không chui vào server sau CGNAT) để thiết bị ở xa POST vào `https://fbt-server.<tailnet>.ts.net`. Ghi hướng dẫn vào plan mục 8c.
