## Hợp đồng OTA với firmware FBT-Reader v2.6.8 — chỉ thêm test, không sửa code

Firmware Reader chuyển OTA từ GitHub sang server (kho `products/reader/`, nhật ký gốc
`docs/history/2026-09-18-reader-ota-server.md`). Server đã phục vụ được từ 2026-09-11; hôm nay
ghim đúng 3 request firmware gửi thành `tests/test_ota_products.py::test_hop_dong_firmware_reader`:

- `PUT /ota/reader` không tên với ảnh thẻ `FBTIMG1;product=reader;ver=v2.6.8;hw=;;` → server đặt
  `reader_v2.6.8.bin`, `hw=None` (Reader gửi `hw=` RỖNG — registry `hw: []` chưa chốt);
  cùng ảnh `PUT /ota/rapidplus` → **400** (thẻ khai `reader`).
- `GET /ota/check?device=RE0012&ver=v2.6.7&product=reader&hw=` → `update:true, ver:"v2.6.8",
  url` tuyệt đối; `…&ver=v2.6.8&updated=1` → `fw_log` mốc `how:"update"`, `fw_seen`
  `product:"reader"`.
- Tải `.bin`: thiếu Bearer 401, có → `x-MD5` đúng md5 file.
- Không khai product, mã `RE…` không có trong `OTA_LEGACY_PRODUCT_BY_PREFIX` → kho legacy
  `rapidplus` (trống) → `{update:false, reason:"none"}`.

Đã chạy thêm với **`firmware.bin` thật** vừa build (1 606 656 B) qua `TestClient`: thẻ đọc ở
offset 10 644, tên/ver/x-MD5 đúng như test. `pytest tests -q` → **97 pass** (venv tạm trong
scratchpad vì shell AI không thấy `%LOCALAPPDATA%\fbt-localtest`).

Không cần deploy: box đang chạy code có kho theo sản phẩm là đủ. Khi phát hành Reader v2.6.8:
