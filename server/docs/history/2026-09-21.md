# 2026-09-21 — `localtest.ps1` chạy được trên máy không có Postgres portable (Docker)

## Vấn đề
Máy `Admin` (khác box ADM) không có Postgres portable, không có Flutter, `python` trên PATH là Python 3.11 của
ESP-IDF; muốn bật server local :8080 để thử tab Hiệu chuẩn (`/calib/*`) mà `localtest.ps1` chỉ biết đường
`$Base\pgsql\bin\pg_ctl.exe` → `throw`.

## Làm gì
- `scripts/localtest.ps1`: không thấy `pg_ctl.exe` ở cả đường mặc định lẫn sandbox gói Claude nhưng có `docker`
  → chế độ **Docker**: container `fbt-localtest-pg` (`postgres:18-alpine`, `POSTGRES_HOST_AUTH_METHOD=trust`,
  volume `fbt-localtest-pgdata` mount ở **`/var/lib/postgresql`** — ảnh PG 18 đổi chỗ, mount `…/data` như PG ≤ 17
  là container thoát ngay với thông báo "unused mount/volume"), cổng `127.0.0.1:5433`. Lần đầu: `docker cp`
  `deploy/schema.sql` vào container + `psql -f`, rồi tạo 3 tài khoản test bằng `scripts/manage_users.py` khi bảng
  `users` trống. `-Stop` = kill uvicorn + `docker stop`. Tự mở Docker Desktop và đợi `docker info` nếu daemon chưa chạy.
- Base mặc định ở chế độ Docker đổi sang `%USERPROFILE%\fbt-localtest` (tránh `AppData\Local` bị sandbox ảo hoá);
  venv tạo bằng `python -m venv` (IDF Python có ensurepip) + cài thêm `jsonschema`, `python-multipart`.
- Đặt thêm `FBT_CALIB_DIR=$Base\calib` (kho ống chuẩn `app/calib.py`).
- Kiểm: `/openapi.json` 200, `POST /auth login root` ok, `/devices` `[]` (DB sống), `/calib/template` trả lỗi
  nghiệp vụ đúng; `-Stop` rồi bật lại (container đã có → chỉ `docker start`) lên trong ~5 s.

## Lệnh hằng ngày
```powershell
Set-Location C:\Users\Admin\Documents\06.ToolEngineer\server; .\scripts\localtest.ps1        # bật
.\scripts\localtest.ps1 -Stop                                                                 # tắt
```
PowerShell của người dùng trên máy Admin có `ExecutionPolicy = Restricted` ("running scripts is disabled") →
gọi `powershell -ExecutionPolicy Bypass -File …\localtest.ps1 [-Stop]`, hoặc tự mở một lần
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` (tool AI chạy script được vì shell của nó không bị chặn).
Web `/app/`: chiều cùng ngày đã cài Flutter 3.44.1 (`C:\Users\Admin\fvm\versions\3.44.1`, clone shallow tag) và
build `apps/fbt_rapid/build/web` trỏ localhost → `/app/` lên, đăng nhập root OK, tab Hiệu chuẩn gọi
`GET /calib/batches` 200. Sau mỗi lần build lại web phải chạy lại `localtest.ps1` (mount lúc khởi động).
Gọi `localtest.ps1` lồng qua `powershell -File` từ tool PowerShell của AI bị TREO tới timeout (uvicorn con giữ
pipe) — server vẫn lên; kiểm bằng `curl /app/` thay vì đợi lệnh trả về.

# 2026-09-21 — Ống chuẩn hiệu chuẩn quang: `app/calib.py` + `/calib/*` (thay Sheet + Apps Script)

## Vì sao
Bàn giao của Khai (`KHAI'S HANDOVER.md` + sheet "RAPIDPlus calibration tubes"): pha Fluorescein 1000 →
300/200/100 nM, chia 25 µL × 10 ống, đọc raw một khe máy Rapid+ rồi gõ vào Google Sheet, Apps Script thử mọi tổ
hợp xếp R²/slope, tổ hợp tốt bỏ túi zip cất tủ lạnh. Không truy vết được lô stock, ai pha, bộ nào đã cấp cho máy
nào. Chủ dự án chốt: tab Flutter + vòng đời bộ ống + quyền root/admin/manager/operator.

## Làm gì
- `app/calib.py` (mới): `plan_steps`/`template` (bảng pha C1·V1 = C2·V2 khớp bàn giao: 10+510, 90+210, 60+240,
  30+270), `linear_fit`, `blank_stats` + `lod_nM` (**LOD = 3,3·STDEV.S(blank)/slope** theo template
  `LOD_template_Fluo_240717` của WI DxD Hub 07/2024), `rank_combinations` (mọi tổ hợp, R²↓ rồi slope↓, PASS theo
  ngưỡng, **suggested_sets không trùng ống**), kho file `CALIB_DIR/{batches,sets}/*.json` + `limits.json` +
  `history.jsonl`, `create_sets` tính LẠI hồi quy + chặn ống trùng bộ, `update_set` theo `SET_TRANSITIONS`.
- `config.py`: `CALIB_DIR` (`FBT_CALIB_DIR`, mặc định `~/fbt_server/calib`); `deploy/fbt-receiver.env.example`.
- `main.py`: 13 route `/calib/*` (GET/PUT/DELETE, không POST), `_calib_call` map `CalibError` → HTTPException.
- `tests/test_calib.py`: 13 test — số liệu sheet bàn giao (tổ hợp tốt nhất 300/3·200/2·100/3·0/3, slope 3,033,
  R² 0,99998), blank WI (0,2,5,3,2,4,5,6,8,10 → SD 2,991, SNR 9,87, LOD 10,1 khớp ảnh template), luồng lô →
  bước → số đo → xếp hạng → đóng bộ → cấp phát → đóng lô. Cả bộ **130/130**.
- Ngưỡng mặc định: `r2_min 0,995` (siết hơn WI 0,95 vì bộ ống là vật chuẩn cho cả fleet), `lod_max 20 nM` (WI),
  slope không giới hạn, `shelf_days 90`. **Lệch đơn vị stock**: bàn giao ghi 52 mM nhưng bảng pha 52× chỉ đúng
  với 52 µM → mặc định 52 000 nM, app cảnh báo khi > 1 mM. Chi tiết: `docs/plan/calib-ong-chuan.md`.

## Bẫy gặp
- `os.environ.setdefault("OTA_ADMIN_TOKEN", …)` ở đầu `test_calib.py` làm **19 test `test_ota_products` rớt 401**
  khi chạy cả bộ (file `test_c…` được nạp trước `test_o…`, token admin bật → PUT bằng token máy bị chặn). Sửa:
  `monkeypatch.setattr(config, "OTA_ADMIN_TOKEN", …)` trong đúng test cần.
- Heredoc bash chứa backtick/nháy lẫn lộn vỡ parse ("unexpected EOF") → script patch ghi ra FILE bằng Write tool
  (đúng gotcha CLAUDE.md gốc).

`flutter analyze` (máy Admin không có Flutter) — xem `docs/history/2026-09-21-calib-ong-chuan.md` ở gốc.
