## Code Giai đoạn 1: nạp PostgreSQL + API đọc cho Flutter (chờ deploy)
- Viết `app.py` (FastAPI, thay `receiver.py`): POST catch-all mọi path (giữ tương thích thiết bị cũ) → **ghi file gốc trước, INSERT PostgreSQL sau** (DB lỗi vẫn trả 200, file còn để nạp bù); validate nhẹ (id_device bắt buộc, các mảng RPL nếu có phải đủ 10 phần tử); chống trùng bằng sha256 nội dung đã chuẩn hóa (tên file + cột UNIQUE); 4 endpoint đọc: `/devices`, `/sessions` (lọc device/ngày + phân trang), `/sessions/{id}` (bỏ amplification), `/sessions/{id}/amplification` (parse CSV → mảng số cho fl_chart); auth 1 Bearer token; Swagger `/docs`.
- Viết `reconcile.py`: nạp bù/import file cũ vào DB, idempotent, received_at lấy theo mtime file.
- Viết `deploy/schema.sql` (bảng `sessions` + index + role `engineer` peer-auth) và `deploy/fbt-receiver.service` (uvicorn từ venv, `EnvironmentFile=/etc/fbt-receiver.env`).
- Test local: `app.py --selftest` pass (Python 3.12); smoke test TestClient pass (401/400, file-first, retry không sinh file rác, chống path traversal, DB chết vẫn nhận data).
- Review đa agent code mới (3 reviewer + 2 skeptic kiểm chứng đối kháng mỗi finding, 17 agent): **3 lỗi xác nhận, đã sửa cả 3**; 4 finding bị bác bỏ.
  1. `app.py` (cao): request chunked không có Content-Length vượt qua check 16MB, `request.body()` buffer vô hạn vào RAM 3.7GB → DoS OOM. Sửa: bắt buộc Content-Length hợp lệ (411) như receiver cũ — thiết bị không phải đổi gì.
  2. `reconcile.py` (vừa): 1 file "độc" (jsonb Postgres từ chối: escape `\u0000`, NaN...) làm crash giữa vòng lặp, chặn vĩnh viễn việc nạp bù các file sau. Sửa: try/except quanh insert, SKIP + đếm.
  3. Quy trình deploy (cao): unit mới đòi `EnvironmentFile=/etc/fbt-receiver.env` nhưng file chưa tồn tại trên server → service fail nếu restart trước. Sửa: khối lệnh deploy tạo env file + venv + copy code TRƯỚC khi thay unit/restart.
